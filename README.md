# 4-Bit ALU (Arithmetic Logic Unit)

## Overview
This project implements a 4-Bit Arithmetic Logic Unit (ALU) using Verilog HDL. The ALU performs basic arithmetic and logical operations on two 4-bit inputs and generates a 4-bit output along with a carry output.

## Features
- 4-bit Addition
- 4-bit Subtraction
- AND Operation
- OR Operation
- XOR Operation
- NOT Operation
- Carry Output Generation

## Inputs
- A[3:0] : First 4-bit input
- B[3:0] : Second 4-bit input
- Select Lines : Used to choose the desired operation

## Outputs
- Result[3:0] : 4-bit output result
- Carry Out : Carry generated during arithmetic operations

## Tools Used
- Verilog HDL
- Visual Studio Code (VS Code)
- GitHub

## Project Files
- alu.v
- testbench.v

## How to Run
1. Clone the repository.
2. Open the project in VS Code.
3. Compile the Verilog files using a Verilog simulator.
4. Run the testbench.
5. Observe the output waveform or console results.
